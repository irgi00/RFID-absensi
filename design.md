# Design System — Absensi Mahasiswa RFID

## Tujuan
Dokumen ini hanya menjadi acuan visual UI/UX.
Dokumen ini tidak boleh mengubah alur bisnis, database, API, atau aturan validasi pada plan.md.

## Gaya Visual
- Desktop-first admin dashboard.
- Bahasa Indonesia.
- Tampilan profesional, modern, dan mudah dibaca.
- Latar belakang terang.
- Sidebar tetap di kiri.
- Card dengan sudut membulat dan bayangan tipis.
- Tabel harus mudah dibaca untuk data absensi.

## Warna Status
- Primary: navy blue.
- Success / Hadir: hijau atau emerald.
- Terlambat: amber/oranye.
- Tidak hadir / error: merah.
- Netral / nonaktif: abu-abu.

## Aturan Penting
- Jangan mengubah API, tabel database, role, atau aturan absensi dari plan.md.
- Desain hanya diterapkan pada tampilan dan komponen UI.
- Gunakan komponen reusable untuk sidebar, header, badge status, tabel, tombol, dan modal.
